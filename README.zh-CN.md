# Sky 天 · 个人网站

[English](README.en.md) · [仓库首页](README.md) · [访问网站](https://skyxiangtian13152.github.io/)

这是 Sky 天的互动式个人网站，以《第五人格》庄园为灵感。访客从封面选择人物，经过缪斯印记过场后进入三维大厅，再通过房间内的入口探索个人内容。网页对原游戏场景、人物、音效和动画做了浏览器适配，画面与原游戏可能存在差异。

## 网站内容

- **关于我**：个人档案、教育背景及联系方式。
- **专业学习**：UNSW 学习经历与课程。
- **作品集**：个人项目介绍、GitHub 链接及交互示意。
- **兴趣爱好、游戏合集、项目珍藏**：兴趣、游戏和推荐的 GitHub 项目。
- **名人墙、宠物小屋、人生足迹**：人物、宠物与个人经历的展示空间。

内容会随着庄园主发布更新；部分页面可能暂时没有条目。网站支持中英文切换，游客无需登录即可浏览。

## 如何浏览

- 在封面选择访客并进入大厅；女性访客可在大厅内切换兜帽形态。更换访客请先返回封面。
- 电脑端使用 **W、A、S、D** 或方向键移动，拖动观察房间，**Q / R** 转动视角；靠近入口后按 **E** 阅读。
- 手机端可使用移动摇杆和阅读按钮，横屏能显示更大的画面。
- 声音默认开启，可通过页面上的声音按钮关闭。部分浏览器会在首次点击、触摸或按键后才允许播放声音；大厅音乐在缪斯过场结束后开始。

## 本地预览

本仓库的 `dist/` 是静态网站文件。安装 Node.js 20 或更新版本后，在仓库目录运行：

```bash
npm start
```

打开 <http://127.0.0.1:4173/>，按 `Ctrl+C` 停止。若端口被占用，可运行 `npm start -- 4174`。此静态预览不需要安装项目依赖；使用本地服务器可以正常加载浏览器需要的资源。静态预览并不包含独立运行的庄园主管理后台。

```bash
npm run check
```

上面的检查用于核对静态资源引用和 JavaScript 语法。

## 内容管理与部署

游客只读取公开内容。庄园主可通过 [管理册](https://sky-tian-manor-portfolio.perky-berry-1262.chatgpt.site/admin/) 使用 GitHub 登录，编辑内容、保存草稿、预览并发布。管理册依赖独立的服务端；本仓库中的静态网站不是完整的管理后台。使用方法见 [OWNER-EDITOR.md](OWNER-EDITOR.md)。

`main` 分支更新后，GitHub Actions 会检查并发布 `dist/` 到 GitHub Pages。已连接的 EdgeOne Pages 项目也从该分支自动部署，配置与说明见 [EDGEONE-DEPLOY.md](EDGEONE-DEPLOY.md)。

| 路径 | 作用 |
| --- | --- |
| `dist/` | 已发布的静态网站、素材与公开内容快照 |
| `scripts/` | 本地预览和静态资源检查 |
| `.github/workflows/pages.yml` | GitHub Pages 发布流程 |
| `OWNER-EDITOR.md` | 庄园主管理和维护说明 |
| `THIRD_PARTY_NOTICES.md`、`licenses/` | 第三方素材来源与许可信息 |
